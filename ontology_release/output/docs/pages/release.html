H₂KG 2.2

Intrinsic taxonomy and contextual workflow use

The recommended complete distribution combines the H₂KG taxonomy, value-free SHACL workflow profiles, and QUDT guidance. Scientific quantities remain Properties or Characteristics; their use as selected inputs is represented through Parameter records and the hasParameter / ofProperty path.

The 2.2 correction ledger records 626 parent and definition decisions across 544 classes. It distinguishes applied corrections, replacements, splits, retained decisions, and source-ambiguous compatibility terms.

The compatibility graph is retained only for migration and may contain legacy class-level workflow assertions. It does not drive canonical outputs or Explore.

External semantic alignment

H₂KG 2.2.0 publishes a separate semantic bridge derived from the frozen TIB snapshot dated 2026-10-14T07:32:20+00:00. The bridge contains 256 asserted mappings covering 168 H₂KG classes and 31 external ontologies.

  • Discovery scope: 3 TIB collections, 143 unique ontologies, 165 collection memberships
  • TIB benchmark assertions: 245 (skos:broadMatch=83, skos:exactMatch=140, skos:narrowMatch=22)
  • Foundational mappings: 11
  • Asserted relations: rdfs:subClassOf=2, rdfs:subPropertyOf=1, skos:broadMatch=83, skos:exactMatch=148, skos:narrowMatch=22
  • Principal benchmark ontologies: afo (36), chmo (32), voc4cat (26), chebi (16), sio (16), kitmtxx (14), bao (11), emmo (11)

Foundational dependencies and reused vocabularies such as HDO, EMMO, QUDT, ChEBI, PROV-O, and DCTERMS remain distinct from ontologies aligned through the TIB benchmark. Asserted bridge links use the original external ontology IRIs; TIB catalogue URLs are retained only as provenance and discovery links. No NFDI collection is imported wholesale.
