# H2KG application evaluation package

This package combines reproducible machine checks with traceable application-level semantic assessment.

## Completed reproducible checks

- DECODE concepts: 35 public H2KG outcomes and 538 DECODE-local outcomes out of 573 canonical source concepts.
- ITC overlap: 11 of 44 ITC fields occur in the 573-concept source registry; 33 are profile-overlay-only fields.
- Retrieval: 4 named tasks with independently labelled results and a precisely defined label baseline. No precision or recall estimate is claimed.
- Semantic assessment: 5486 item-level records across ITC fields, DECODE concepts and edges, the H2KG taxonomy sample, and asserted external mappings.
- Comparator evaluation: 20 evidence-backed task outcomes across H2KG, EDO, HDO, and HOLY, without an aggregate score.
- BattINFO is retained as a TIB catalogue membership but is not assigned semantic outcomes because native frozen evidence is unavailable.

## Interpretation boundary

Acceptance of a DECODE-local concept confirms its project-local identity and role only. It does not create an H2KG class, W3ID identifier, synonym, or external mapping. Historical disagreement and adjudication counts were not retained in the source evidence and are therefore not reported as zero.
