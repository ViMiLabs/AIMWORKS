Fair comparison protocol

All thirteen requirements were derived from the same characterization-record lifecycle and named by scientific function rather than ontology origin. Both ABoxes were generated independently from the same frozen manifest. Each requirement was scored once over the full case population; native, generic, declared-import, and shared-standard support are distinguished explicitly. The contract and five decision rules were hashed before query execution, and the conclusion was emitted only because all five rules passed.

Conclusion

The benchmark supports the conclusion that CHAMEO provides broad characterization methodology, while H₂KG complements it with hydrogen-domain specificity and direct valued-parameter and individually provenance-linked result patterns.

This is a conclusive result for the frozen thirteen-requirement characterization knowledge-graph benchmark over the eight workbook-derived cases. Governance, maintainability, reasoning performance, usability, and scalability were not measured.
